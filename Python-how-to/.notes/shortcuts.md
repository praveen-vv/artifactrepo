# PyCharm Essential Shortcuts

## General / Navigation

* **`Double Shift`**: **Search Everywhere**
    * The ultimate search tool. Find files, classes, actions, settings, and more.
* **`Ctrl + Shift + A`**: **Find Action**
    * Don't remember a shortcut? Use this to find and execute almost any PyCharm action by typing its name.
* **`Ctrl + E`**: **Recent Files**
    * Quickly jump back to recently opened files.
* **`Alt + 1` (or other numbers)**: **Toggle Tool Window**
    * Open or close tool windows (e.g., `Alt + 1` for the Project tool window).
* **`Esc`**: **Go to Editor**
    * Move focus from a tool window back to the code editor.
* **`Ctrl + Tab`**: **Switcher**
    * Switch between open editor tabs, tool windows, and recent files.
* **`Alt + Left/Right Arrow`**: **Navigate Between Tabs**
    * Move between open editor tabs.
* **`Ctrl + Alt + Left/Right Arrow`**: **Navigate Back/Forward**
    * Go back to your previous cursor location or move forward.
* **`F4`**: **Jump to Source**
    * Quickly jump to the definition of the symbol under your cursor.
* **`Ctrl + F12`**: **File Structure Popup**
    * View the structure of the current file (functions, classes, variables) and navigate quickly.
* **`Ctrl + Alt + Insert`**: **New object**

## Editing & Code Completion

* **`Alt + Enter`**: **Show Intention Actions / Quick Fixes**
    * Your best friend for context-sensitive actions, error/warning fixes, and code improvement suggestions (e.g., adding imports, generating code).
* **`Ctrl + Space`**: **Basic Code Completion**
    * Provides basic code completion suggestions.
* **`Ctrl + Shift + Space`**: **Smart Code Completion**
    * Offers more intelligent and context-aware code completion.
* **`Ctrl + P`**: **Parameter Info**
    * Displays information about the parameters of the function you're currently calling.
* **`Ctrl + Q`**: **Quick Documentation**
    * Shows documentation for the symbol at the caret.
* **`Ctrl + /`**: **Comment/Uncomment Line**
    * Toggles line comments (for a single line or selected block).
* **`Ctrl + Shift + /`**: **Comment/Uncomment Block**
    * Toggles block comments for selected code.
* **`Ctrl + D`**: **Duplicate Line or Selection**
    * Duplicates the current line or the selected block of code.
* **`Ctrl + Y`**: **Delete Line at Caret**
    * Deletes the entire line where your cursor is.
* **`Ctrl + Shift + Up/Down Arrow`**: **Move Line Up/Down**
    * Moves the current line or selected block of code up or down.
* **`Ctrl + Shift + Enter`**: **Complete Statement**
    * Adds necessary syntax (e.g., parentheses, braces, semicolons) to complete the current statement.
* **`Shift + Enter`**: **Start New Line**
    * Creates a new line below the current one, even if the current line isn't fully completed.
* **`Tab` / `Shift + Tab`**: **Indent / Unindent Lines**
    * Indents or unindents selected lines.
* **`Ctrl + Alt + L`**: **Reformat Code**
    * Formats your code according to your PyCharm code style settings.
* **`Alt + Insert`**: **Generate Code**
    * Opens a menu to generate common code constructs (e.g., constructors, getters, setters, overridden methods).
* **`Ctrl + Alt + Insert`**: **Create Directory** (Windows/Linux)
    * Opens the "New" menu from which you can select "Directory" to create a new folder. (On macOS, use `Command + N` then select "Directory").

## Finding & Replacing

* **`Ctrl + F`**: **Find**
    * Find text within the current file.
* **`Ctrl + R`**: **Replace**
    * Find and replace text within the current file.
* **`Ctrl + Shift + F`**: **Find in Path**
    * Search for text across your entire project or specific directories.
* **`Ctrl + Shift + R`**: **Replace in Path**
    * Find and replace text across your entire project or specific directories.
* **`F3` / `Shift + F3`**: **Next/Previous Occurrence**
    * Navigate to the next or previous occurrence of the found text.

## Refactoring

* **`Shift + F6`**: **Rename**
    * Safely rename a variable, function, class, or file, updating all usages throughout your project.
* **`F5`**: **Copy**
    * Copy files or directories.
* **`F6`**: **Move**
    * Move files or directories.
* **`Ctrl + Alt + M`**: **Extract Method**
    * Extract a block of code into a new method.

---

## Running & Debugging

* **`Shift + F10`**: **Run**
    * Runs the current file or selected run configuration.
* **`Shift + F9`**: **Debug**
    * Debugs the current file or selected run configuration.
* **`F8`**: **Step Over** (during debugging)
    * Executes the current line and moves to the next, without stepping into function calls.
* **`F7`**: **Step Into** (during debugging)
    * Steps into the function call on the current line.
* **`Shift + F8`**: **Step Out** (during debugging)
    * Steps out of the current function and returns to the calling code.
* **`F9`**: **Resume Program** (during debugging)
    * Continues program execution until the next breakpoint.
* **`Ctrl + F8`**: **Toggle Breakpoint**
    * Adds or removes a breakpoint at the current line.

## Learning More Shortcuts

* **Key Promoter X Plugin**: Install this PyCharm plugin to learn shortcuts as you work. It'll notify you with the shortcut whenever you use your mouse for an action.
* **Help -> Keyboard Shortcuts PDF**: PyCharm provides a PDF reference card with all default shortcuts.
* **Settings/Preferences -> Keymap**: Explore these settings to view and customize all available actions and their assigned shortcuts.
* **IDE Features Trainer**: PyCharm includes an interactive trainer under `Help -> Learn IDE Features` to guide you through common tasks and shortcuts.
