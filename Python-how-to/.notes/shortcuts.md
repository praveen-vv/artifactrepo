General / Navigation:
Double Shift: Search Everywhere - The most powerful search in PyCharm. Find files, classes, actions, settings, etc.
Ctrl + Shift + A: Find Action - If you forget a shortcut or want to perform an action without a dedicated one, this is your go-to. Start typing the action name, and PyCharm will suggest it.
Ctrl + E: Recent Files - Quickly navigate to recently opened files.
Alt + 1 (or other numbers): Toggle Tool Window - Quickly open/close the Project tool window (1) or other tool windows.
Esc: Go to Editor - When your focus is in a tool window, pressing Esc will move your cursor back to the editor.
Ctrl + Tab: Switcher - Switch between open editor tabs, tool windows, and recent files.
Alt + Left/Right Arrow: Navigate Between Tabs - Switch between open editor tabs.
Ctrl + Alt + Left/Right Arrow: Navigate Back/Forward - Go back to your previous cursor location or forward.
F4: Jump to Source - Jump to the declaration of a symbol at the caret.
Ctrl + F12: File Structure Popup - See the structure of the current file (functions, classes, variables) and quickly navigate.

Editing & Code Completion:
Alt + Enter: Show Intention Actions / Quick Fixes - This is incredibly useful! It provides context-sensitive actions, quick-fixes for errors/warnings, and suggestions for improving your code (e.g., adding imports, creating methods, reformatting).
Ctrl + Space: Basic Code Completion - Provides basic code completion suggestions.
Ctrl + Shift + Space: Smart Code Completion - Offers more intelligent and context-aware code completion.
Ctrl + P: Parameter Info - Shows information about the parameters of the function you're currently calling.
Ctrl + Q: Quick Documentation - Shows quick documentation for the symbol at the caret.
Ctrl + /: Comment/Uncomment Line - Toggles line comments (single line or selected block).
Ctrl + Shift + /: Comment/Uncomment Block - Toggles block comments (for selected blocks).
Ctrl + D: Duplicate Line or Selection - Duplicates the current line or the selected block of code.
Ctrl + Y: Delete Line at Caret - Deletes the entire line where your cursor is.
Ctrl + Shift + Up/Down Arrow: Move Line Up/Down - Moves the current line or selected block of code up or down.
Ctrl + Shift + Enter: Complete Statement - Adds necessary syntax (e.g., parentheses, braces, semicolons) to complete the current statement.
Shift + Enter: Start New Line - Moves the caret to a new line below the current one, even if the current line isn't fully completed.
Tab / Shift + Tab: Indent / Unindent Lines - Indents or unindents selected lines.
Ctrl + Alt + L: Reformat Code - Formats your code according to your PyCharm code style settings.
Alt + Insert: Generate Code - Opens a menu to generate common code constructs (constructors, getters, setters, override methods, etc.).

Finding & Replacing:
Ctrl + F: Find - Find text within the current file.
Ctrl + R: Replace - Find and replace text within the current file.
Ctrl + Shift + F: Find in Path - Search for text across your entire project or specific directories.
Ctrl + Shift + R: Replace in Path - Find and replace text across your entire project or specific directories.
F3 / Shift + F3: Next/Previous Occurrence - Navigate to the next or previous occurrence of the found text.

Refactoring:
Shift + F6: Rename - Safely rename a variable, function, class, or file, updating all usages throughout your project.
F5 / F6: Copy / Move - Copy or move files/directories. (Note: For creating directories, the shortcut is different as discussed previously).
Ctrl + Alt + M: Extract Method - Extracts a block of code into a new method.

Running & Debugging:
Shift + F10: Run - Runs the current file or selected run configuration.
Shift + F9: Debug - Debugs the current file or selected run configuration.
F8: Step Over (during debugging) - Executes the current line and moves to the next, without stepping into function calls.
F7: Step Into (during debugging) - Steps into the function call on the current line.
Shift + F8: Step Out (during debugging) - Steps out of the current function and returns to the calling code.
F9: Resume Program (during debugging) - Continues program execution until the next breakpoint.
Ctrl + F8: Toggle Breakpoint - Adds or removes a breakpoint at the current line.

Tips for Learning More Shortcuts:
PyCharm's "Key Promoter X" Plugin: This is a fantastic plugin! It will show you a popup notification with the corresponding keyboard shortcut whenever you perform an action using the mouse. It's a great way to learn new shortcuts naturally.
Help -> Keyboard Shortcuts PDF: PyCharm provides a PDF reference card with all the default shortcuts.
Settings/Preferences -> Keymap: Explore the Keymap settings to see all available actions and their assigned shortcuts. You can also customize them here.
IDE Features Trainer: PyCharm includes a built-in interactive trainer under Help -> Learn IDE Features to guide you through common tasks and shortcuts.
